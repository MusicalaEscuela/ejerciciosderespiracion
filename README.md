# Respira Canto | Musicala

Aplicativo web estático para ejercicios interactivos de respiración para canto.

## Qué incluye

- Temporizador por fases: inhalar, pausar, exhalar y descansar.
- Visual del abdomen para reforzar respiración baja.
- Línea de progreso por fase.
- Sonidos opcionales para cambios de fase y pulsos.
- Biblioteca de ejercicios filtrable.
- Rutina recomendada.
- Creador de rutina personalizada.
- Estadísticas locales guardadas en el navegador con `localStorage`.
- Diseño claro estilo Musicala, apto para GitHub Pages.

## Cómo usar

1. Sube todos los archivos a un repositorio de GitHub Pages o abre `index.html` directamente.
2. Abre la página y selecciona un ejercicio o inicia la rutina recomendada.

## Archivos

- `index.html`: estructura de la app.
- `styles.css`: diseño visual con la paleta institucional de Musicala.
- `logo.png`: logo oficial de Musicala.
- `app.js`: ejercicios, temporizador, rutinas e interactividad.
- `README.md`: esta guía.
